# Memory Production Qualification A29 Brief

Status: approved implementation scope for bounded production closure.

## Objective

Prove that the A25-qualified, A26-selected retrieval policy is the route used
by ordinary Chat and Voice context assembly, remains canonical-ledger sourced,
and fails back to local retrieval if projection evidence is unavailable. Close
the sequence with deterministic evidence for audit reconstruction, lifecycle
compensation, Core-aware execution, projection reconciliation, backup scope,
and the read-only A28 visualization boundary.

## Live qualification

The foreground `soul-memory-production-qualify` command reads the existing
owner-private A24 corpus and active A26 selector, and issues every case through
the public `ApplicationFacade` `memory.observatory.query` operation. It accepts only the exact
`projection_gate_local_order_a29` route with threshold `0.55`, an available A23
projection, canonical local content joins, approved opaque memory identifiers,
and mutation-free envelopes. Its output contains case identifiers, query
digests, counts, ranks, and route identity only; query text and memory content
are withheld.

## Closure matrix

The A29 closure verifier runs the accepted A25 through A28 verifiers plus the
existing audit reconstruction, live lifecycle qualification, Core-aware worker,
projection compensation, Core settlement, and backup-administration checks.
`Soul/private/` remains within the encrypted P0 backup scope. Restore-to-path
testing remains governed by Backup & Recovery and is not reimplemented here.

## Bounds and authority

- The live operation is foreground, read-only, and bounded to 2..48 cases with
  a maximum 300-second timeout.
- Production qualification does not mutate canonical memories, projection
  stores, the active policy, Chat state, Voice state, Core state, or backups.
- Missing policy, projection fallback, content-bearing or mutation-bearing
  envelopes, unapproved identifiers, unsafe files, and malformed input fail
  closed.
- A28 renders only already-bounded privacy-safe metadata. Depth is presentation,
  never semantic similarity, inferred authority, or a new relationship.
- Human review remains the final approval for the 3D appearance and live
  conversational quality.

## Production-environment correction

The first A29 run revealed that the earlier A24/A25 command path had not loaded
the same reviewed `.env` as the Dashboard facade. With production configuration
loaded, `0.65` retained 10/11 positive hits. The closed A24 sweep showed `0.55`
retained 11/11 positive hits, all 5 negative abstentions, and zero forbidden
hits. The original A25 profile remains unchanged; A29 uses the distinctly named
`projection_gate_local_order_a29` profile so the correction is explicit,
auditable, and reversible.
