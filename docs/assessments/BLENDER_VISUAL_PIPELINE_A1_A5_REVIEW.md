## Known limits

- Creative-direction prose is retained with the candidate but does not yet
  compile into arbitrary geometry. Template choice controls construction.
- The adapter uses primitive geometry and deterministic bevel/smoothing. Dense
  authored foliage, bespoke meshes, texture packs, curves, characters, rigs,
  and simulation presets need separately reviewed allowlists.
- EEVEE is the only Dashboard render profile. Cycles devices are inventoried,
  but Cycles has not passed visual-benefit and runtime qualification.
- Production frame sets are larger than diffusion loops. Failed partial frames
  are retained only for explicit resume; there is no automatic retry or
  background worker.
- Blender 5.2 node-enable APIs used by the adapter are deprecated for Blender
  6. The runtime pin must not change without adapter qualification.
